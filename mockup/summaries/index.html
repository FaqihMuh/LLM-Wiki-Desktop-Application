Topic Agent Memory
Source 2602.02007v3.pdf
Entities 3

Overview

This paper introduces xMemory, a retrieval architecture designed to improve long-term memory retrieval for autonomous AI agents by separating retrieval from evidence aggregation.

Key Contributions

  • Introduces xMemory framework.
  • Improves evidence coverage.
  • Reduces redundant retrieval.
  • Supports long-term agent memory.
